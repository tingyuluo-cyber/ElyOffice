# ReimuMark 0.1.22 preview selection

Date: 2026-11-16

Scope: read-only preview text selection, clipboard actions, virtual scrolling and standalone packaging.

Review findings:

- Preview uses the existing renderer's selection and theme highlighting. A complete text index keeps Ctrl+A and copying independent of which blocks are visible. Only visible blocks retain live layouts, and scrolling invalidates old geometry.
- Forward and backward dragging, Shift-click extension and right-click copying use rendered text. Source documents and undo history remain unchanged. Switching modes or replacing text clears the selection; pending parses expose no stale selection.
- Paragraphs, headings, nested lists, tasks, tables, code, front matter and literal definitions share traversal order. Inline math maps pointer positions and highlights back to its original text rather than copying layout glue.
- Dragging a link selects its label without opening it. Plain link clicks and accessible task checkbox activation keep their existing behavior. Preview picture presses still reach the application's context menu.
- Rendering helpers were moved into the existing renderer module to keep changed Rust files below 500 lines. No document contents are logged.

- `cargo clippy --locked -p ely-documents -p ely-mark --all-targets --features ely-documents/test-support -- -D warnings`: passed. The host reported incremental-cache hard-link fallback warnings.
- The extracted standalone package printed `ready ElyMark` and exited 0. Its executable matches the release build.
- All three user documents were verified saved before replacement. The installed executable was backed up, replaced and restarted.
